# theme.allia

Thème déclaratif (aucun code) pour le mode hébergé : charte Allia, icônes lucide, Bricolage Grotesque / Manrope / JetBrains Mono auto-hébergées (pas de CDN). Clair uniquement (mode sombre Allia non défini). Cibles tactiles 44 px (`--vds-touch-target`).

Mêmes contrats que `theme.vtech` (`--vds-*`, `.vds-icon[data-icon]`, `.vds-logo`).

Limites : `assets/logo.svg` est un PLACEHOLDER textuel ; remplacer par le SVG officiel du Studio (`public/brand/*.svg`), jamais redessiné. Couleurs d'état à valider.
