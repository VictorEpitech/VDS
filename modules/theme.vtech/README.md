# theme.vtech

Thème déclaratif (aucun code) : charte V-Tech MD3, clair et sombre (`prefers-color-scheme`, surchargeable par `data-theme`), Material Symbols Outlined weight 300, polices auto-hébergées (Inter, Roboto, JetBrains Mono, licence OFL).

Contrat des composants : variables `--vds-*`, `<span class="vds-icon" data-icon="online">`, `<span class="vds-logo">`. Les noms d'icônes sont sémantiques (`online`, `scheduled_off`, `offline`, `power_failed`, `overridden`, `pairing`, `back`, `logout`, `user`, `language`, `screen`, `warning`) ; chaque thème les relie à sa bibliothèque.

Limites : logo = marque provisoire (logo V-Tech officiel à fournir) ; couleurs d'état à valider.
